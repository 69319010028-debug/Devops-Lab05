# Jigsaw Puzzle Game Plan

## 1. วัตถุประสงค์ของโปรเจกต์

สร้างเกม Jigsaw Puzzle ที่เล่นผ่าน Browser บนเครื่องคอมพิวเตอร์ โดยใช้ภาษา HTML, CSS และ JavaScript

- ใช้รูปภาพ `porche.jpeg` เป็นภาพหลัก
- แบ่งภาพเป็น 20 ชิ้น (5 x 4)
- ผู้เล่นต้องเรียงชิ้นภาพให้ถูกต้องตามตำแหน่งเดิม
- เกมสามารถเล่นได้ทันทีในหน้าเว็บโดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติม

## 2. ข้อกำหนดของเกม

1. เป็นเกมที่เล่นผ่าน Browser ของเครื่อง PC
2. พัฒนาโดยใช้ HTML + CSS + JavaScript
3. ใช้รูป `porche.jpeg` เป็นรูปหลัก
4. แบ่งภาพเป็น Jigsaw Puzzle จำนวน 20 ชิ้น
5. เกมต้องมีการสับชิ้นรูปแบบสุ่ม
6. ผู้เล่นสามารถลากหรือคลิกเรียงชิ้นภาพ
7. มีการตรวจว่าชิ้นภาพถูกเรียงครบหรือยัง
8. มีปุ่มเริ่มเกม / สับใหม่ / รีเซ็ตเกม

## 4. โครงสร้างหน้าเว็บ

### `index.html`
- บรรจุ layout หลักของเกม
- มีพื้นที่แสดง Puzzle Board
- มีแถบข้อมูล เช่น เวลา, สถิติ, ปุ่มควบคุม
- มีข้อความแจ้งสถานะ เช่น เริ่มเกม / ชนะเกม

### `style.css`
- จัดหน้าเกมให้สวยงามและใช้งานง่ายบน PC
- กำหนดขนาด board ของ puzzle
- กำหนดลักษณะชิ้น puzzle เช่น ขนาด, เส้นขอบ, hover, drag effect
- จัด layout ให้มีหน้าตาเป็นเกม Jigsaw ที่เข้าใจง่าย

### `script.js`
- โหลดรูป `porche.jpeg`
- แบ่งภาพออกเป็น 20 ชิ้น
- สร้าง data ของแต่ละชิ้น เช่น ตำแหน่งที่ถูกต้อง, ตำแหน่งปัจจุบัน
- สลับชิ้นภาพแบบสุ่ม
- จัดการเคลื่อนไหว เช่น drag/drop หรือ click-to-place
- ตรวจว่าผู้เล่นชนะเกมหรือยัง

## 5. รูปแบบการทำ Puzzle

จัดรูปภาพเป็น Grid 5 x 4 = 20 ชิ้น

- จำนวนแถว: 4
- จำนวนคอลัมน์: 5
- แต่ละชิ้นจะมี background image จาก `porche.jpeg`
- ใช้ `background-size` และ `background-position` เพื่อแสดงส่วนของภาพที่ตรงกับชิ้นนั้น
- ตำแหน่งที่ถูกต้องสำหรับแต่ละชิ้นจะถูกเก็บไว้ใน JavaScript

## 6. Logic หลักของเกม

### 6.1 การสร้างชิ้นรูป
- โหลดภาพ `porche.jpeg`
- คำนวณความกว้างและความสูงของภาพเพื่อจัดสัดส่วนให้เข้ากับ board
- สร้าง 20 element สำหรับชิ้นภาพ
- กำหนด background image ของแต่ละชิ้นตามตำแหน่งจริง

### 6.2 การสับชิ้น
- ระบุตำแหน่งที่ถูกต้องของแต่ละชิ้น
- สุ่มตำแหน่งใหม่ให้แต่ละชิ้น
- ตรวจให้ทุกชิ้นอยู่ในตำแหน่งที่ไม่ซ้ำกัน

### 6.3 การจัดการการเล่น
- ผู้เล่นจะลากชิ้นหนึ่งลงในช่องที่ตรงกัน
- หรือคลิกชิ้นแล้วเลือกช่องเป้าหมาย
- หากวางผิด จะไม่ยอมให้ติดตำแหน่ง
- หากวางถูก จะล็อกชิ้นนั้นไว้

### 6.4 การตรวจชัยชนะ
- เมื่อครบ 20 ชิ้นถูกต้อง จะมีข้อความว่า “You Win!”
- อาจเพิ่มเสียงหรือเอฟเฟกต์สั้น ๆ สำหรับความรู้สึกของการชนะ

- จัด layout 2 ส่วนหลัก:
  - ซ้าย: Puzzle board
  - ขวา: ปุ่มและข้อมูลเกม
- สีสันควรดูสอดคล้องกับรูปภาพรถ Porsche
- ใช้เส้นขอบและเงาเพื่อให้ชิ้นภาพดูเป็นชิ้นจริง

## 9. ขั้นตอนการพัฒนา

### Phase 1: สร้างโครงสร้างพื้นฐาน
- สร้าง `index.html`
- เพิ่มปุ่มและ layout หลัก

### Phase 2: สร้างสไตล์ CSS
- จัดหน้า, board, button, status panel

### Phase 3: สร้าง logic Puzzle
- โหลดภาพ
- แบ่งภาพออกเป็น 20 ชิ้น
- กำหนดข้อมูลชิ้นภาพ

### Phase 4: เพิ่มการสับชิ้น
- สุ่มตำแหน่งชิ้น
- ทำให้ชิ้นเรียงแบบสุ่ม

### Phase 5: เพิ่มการเล่น
- Drag and drop หรือ click to place
- ตรวจความถูกต้อง

### Phase 6: ทดสอบและปรับปรุง
- ทดสอบการเล่นบน browser
- จัดการความผิดพลาดเรื่องตำแหน่ง
- ปรับ UI เพื่อให้เล่นง่ายขึ้น

## 10. ปัญหาที่อาจพบและแนวทางแก้ไข

### ปัญหา: ชิ้นภาพไม่ตรงตำแหน่ง
- ตรวจ `background-position` ให้ถูกต้อง
- ตรวจว่า `background-size` คำนวณตาม board size ถูกต้อง

### ปัญหา: แบ่งชิ้นไม่สมบูรณ์
- ตรวจจำนวนแถวและคอลัมน์ต้องเป็น 4 x 5
- ตรวจให้แต่ละชิ้นมี `data-index` และ `correctPosition` ที่ถูกต้อง

### ปัญหา: การลากชิ้นไม่สะดวก
- ใช้ drag/drop แบบง่าย
- หรือใช้ click-select + drop-zone แบบชัดเจน

### ปัญหา: เกมไม่รู้ว่าชนะ
- ควรมีตัวแปรเก็บสถานะการวางแต่ละชิ้น
- เมื่อครบทุกชิ้นแล้วให้ set status เป็น “win”
